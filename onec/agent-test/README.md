# Агент TEST 1С — инструкция

Читайте [docs/1c-test-agent.md](../../docs/1c-test-agent.md).

Выполняйте в 32-битном PowerShell на Windows с тестовой 1С:

1. `01-Configure.ps1` — создать локальную конфигурацию и шифрованные секреты.
2. `02-Read-Test.ps1` — только прочитать товар из TEST.
3. В Конфигураторе собрать отдельную `TEXHORU-TEST-Agent.epf` из `../monitoring/UT103-TEST-Agent-ObjectModule.bsl` (модуль объекта).
4. `03-Check-EPF.ps1` — только проверить чтение розничной цены Xiaomi.
5. `04-Install-Schedule.ps1` — задание каждые 5 минут, пока без записи.
6. **Только после проверки:** `05-Enable-TEST-Writes.ps1` — явно разрешить запись одного товара в TEST.
7. `STOP-Agent.ps1` — отключить и удалить расписание.

**Не отправляйте ключи и пароли в чат. Не запускайте на базе base.**
