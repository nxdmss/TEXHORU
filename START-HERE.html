Запуск магазина

Для обычной работы не нужно открывать файлы программы или вводить команды.

  1. Открой папку с TEXHORU на своём компьютере.
  2. Запусти TEXHORU.exe. Если его нет, открой TEXHORU-WINDOWS.cmd.
  3. Дождись открытия сайта в браузере. При первом запуске понадобится интернет.
  4. Для управления магазином открой страницу управления.

Как остановить: запусти TEXHORU STOP.exe или TEXHORU-STOP-WINDOWS.cmd. Обычная остановка сохраняет товары, историю и фотографии.

Если программа не открылась

Сохрани сообщение об ошибке. Для программиста полезен файл .texhoru/startup.log из папки проекта.

Не запускай TEXHORU-RESET.cmd для исправления ошибки. Это отдельная команда для сброса данных, а не для обычного обновления.

Как работать с ценами

Открой Управление → Цены. Сайт проверяет 05.ru и предлагает цены на 100 ₽ ниже. Выдели нужные товары и только потом нажми «Отправить выбранные в 1С».

О проекте Цены и 1С Для программиста
Автоматический агент тестовой 1С ещё нужно испытать на конкретном компьютере. Продуктивную базу нельзя подключать без отдельного разрешения и проверки.
