TEXHORU · WINDOWS

Нажми TEXHORU.exe.
Приложение подготовится само.

  1. Открой папку TEXHORU внутри архива. Скопируй её содержимое в свою папку TEXHORU с заменой файлов.
  2. Нажми TEXHORU.exe. Если старая версия ещё запущена — сначала закрой её окно.
  3. Подожди: при первом запуске нужны интернет и несколько минут. Сайт откроется автоматически.

База и фотографии остаются в твоей папке. Перед обновлением схемы создаётся резервная копия. Старую папку зависимостей удалять вручную не нужно.

Дальше всё теми же кнопками

TEXHORU.exe — запустить.
TEXHORU STOP.exe — остановить.

Если запуск остановился

Пришли последние строки из .texhoru/startup.log. Команды сброса базы и npm audit fix --force выполнять не нужно.

Подключение 1С

Сначала проверяем запуск сайта. Тексты модулей обмена находятся в onec/monitoring; их нужно установить в твою конкретную учебную базу. Подробная инструкция для 1С.

Windows EXE собран. Автоматическая подготовка, запуск сайта, сохранение данных и остановка проверены в Linux. Запуск самого EXE на твоём Windows ещё нужно подтвердить.
