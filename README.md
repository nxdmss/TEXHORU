# TEXHORU — CLEAN DEV

Чистая локальная версия проекта без старых BAT/VBS/архивов и временных скриптов.

## Запуск

Дважды нажми `TEXHORU.exe`.

Он сам:

- проверит Node.js и npm;
- при первом запуске установит зависимости;
- подготовит Prisma + SQLite;
- запустит NestJS API на `http://127.0.0.1:3000`;
- запустит Vite на `http://127.0.0.1:5173`;
- откроет магазин в браузере;
- оставит hot reload включённым для разработки.

Повторный запуск `TEXHORU.exe`, когда серверы уже работают, просто откроет сайт ещё раз.

## Перенос существующих товаров и фото

Рекомендуемая новая папка: `C:\TEXHORU`.

Не удаляй старый проект до проверки новой версии. При первом запуске `TEXHORU.exe` ищет существующий локальный проект в обычных местах, включая старую папку на OneDrive/Desktop, и если новая база ещё не создана, переносит:

- `server\prisma\dev-local.db`;
- `server\uploads`;
- `server\.env.local`.

После запуска проверь каталог и админку, и только потом удаляй старую папку.

## Адреса

- Магазин: `http://127.0.0.1:5173/`
- Админка: `http://127.0.0.1:5173/admin`
- API health: `http://127.0.0.1:3000/api/health`

Локальный dev-администратор для новой пустой базы:

- `director@texhoru.local`
- `ChangeMe123!`

## Логи

Если что-то не запускается, смотри скрытую папку `.texhoru`:

- `launcher.log`
- `setup.log`
- `backend.log`
- `frontend.log`

## Что намеренно отсутствует

В этой чистой версии нет старых `START_*`, `SETUP_*`, `REBUILD_*`, Docker/Yandex deploy-файлов, архивов обновлений, `node_modules`, `dist` и временных логов. Их наличие не требуется для обычной локальной разработки.
