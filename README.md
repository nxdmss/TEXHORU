# TEXHORU

**Интернет-магазин электроники с учётом товаров в 1С и проверкой цен на 05.ru.**

Магазин показывает товары и остатки. Сотрудник видит цены конкурента, выбирает нужные изменения и отправляет их в тестовую 1С. Сайт не меняет цену по решению парсера.

## Как пользоваться

| Задача | Где находится |
| --- | --- |
| Добавить или найти товар | **Управление магазином → Товары** |
| Проверить цены конкурента | **Управление магазином → Цены** |
| Выбрать новые цены | **Цены → Предложения → Отправить выбранные в 1С** |
| Посмотреть результат отправки | **Управление магазином → Обмен с 1С** |
| Проверить заказы | **Управление магазином → Заказы** |

**Правило предложения:** цена на 05.ru минус 100 ₽. Себестоимость пока не проверяется. Изменение больше 10% от нашей цены остаётся заблокированным. Сотрудник сам решает, какие позиции передать.

О том, что делать при отсутствии предложения или связи с 1С, написано в [инструкции по ценам](docs/как-работать-с-ценами.md).

## Запуск

### На Windows

1. Открой папку с установленным проектом.
2. Запусти **TEXHORU.exe** (если он есть в твоей сборке). Для исходного проекта есть **TEXHORU-WINDOWS.cmd**.
3. Открой магазин: http://127.0.0.1:5173
4. Открой управление: http://127.0.0.1:5173/admin

Для остановки используется **TEXHORU STOP.exe** или **TEXHORU-STOP-WINDOWS.cmd**.

**Не запускай TEXHORU-RESET.cmd для обновления.** Он сбрасывает данные, хотя сначала создаёт резервную копию. Обычный запуск и обновление не требуют сброса.

### На macOS

Открой **TEXHORU.command**. Для проверки цен может потребоваться отдельно установленный браузер.

### Для программиста

Нужен Node.js версии 22 или выше.

```bash
npm ci
npm --prefix server ci
cp server/.env.example server/.env.local
export DATABASE_URL=file:./dev-local.db
npm run db:local:generate
npm run db:local:push
npm run dev
```

На Windows файл можно скопировать обычным способом. В PowerShell вместо `export` используй `$env:DATABASE_URL = "file:./dev-local.db"`. Перед запуском проверь значения в `server/.env.local`. Пароли из примера нельзя использовать на доступном из интернета сервере.

После запуска: магазин работает на порту **5173**, сервер на **3000**, проверка работы сервера доступна по адресу http://127.0.0.1:3000/api/health.

## Что находится в проекте

| Папка | Для чего |
| --- | --- |
| `src/` | Страницы магазина и управление |
| `server/src/` | Заказы, товары, цены и связь с 1С |
| `server/prisma/` | Описание базы данных |
| `onec/` | Исходные тексты обработок для 1С |
| `scripts/` | Запуск и обслуживание |
| `docs/` | Инструкции и технические подробности |

Основные данные лежат локально: `server/prisma/dev-local.db`, загруженные изображения — в `server/uploads/`, настройки и ключи — в `server/.env.local`. **Не отправляй эти файлы в GitHub.**

## Состояние обмена с 1С

- Загрузка каталога из 1С и поиск цен 05.ru уже реализованы.
- Исходный код агента Windows и установщик для автоматической обработки очереди добавлены в `onec/agent/`. Сборка `.epf` и проверка на копии УТ 10.3 ещё обязательны.
- Обратная запись цен блокируется, пока тестовый сервер явно не настроен: `ONE_C_BASE_KIND=TEST` и `ONE_C_TEST_PRICE_SYNC_ENABLED=true`.
- Автоматический допуск импортированных товаров можно включить **только для отдельной тестовой 1С**. По умолчанию он выключен.
- Предложения по ценам создаются автоматически, но отправляются в 1С **только по кнопке сотрудника**.
- Публикация новой цены на сайте после подтверждения 1С реализована на стороне TEXHORU.
- **Автоматический агент 1С ещё требует испытания на конкретной тестовой базе Windows.** Нельзя считать систему готовой к записи в рабочую 1С.

Перед передачей проекта следующему программисту открой [памятку разработчику](docs/передача-разработчику.md). Там перечислено, что проверять, где искать код и что ещё не готово.
