## Запуск на Windows

**Чистый старт для презентации парсера:** закрой приложение, открой `TEXHORU-RESET.cmd` и подтверди `RESET-TEXHORU`. База, загруженные файлы и настройки сначала копируются в `backups/`. После сброса запускай `TEXHORU.exe` и импортируй реальные категории/товары из 1С. [Полная инструкция](docs/clean-parser-start.md).

Нажми **TEXHORU.exe**. Зависимости, резервная копия данных и обновление схемы подготавливаются автоматически. На Windows парсер использует установленный Edge без скачивания Chromium. Отдельный ручной установщик не нужен. Остановка — **TEXHORU STOP.exe**.

Первый запуск требует интернета и может занять несколько минут. Зависимости устанавливаются в локальный кеш вне OneDrive; база и фотографии остаются в папке проекта. Короткая инструкция: `START-HERE.html`. Для настройки учебной 1С: [docs/windows-1c-monitoring.md](docs/windows-1c-monitoring.md).


# TEXHORU

TEXHORU — локально запускаемый интернет-магазин электроники с React/Vite frontend, NestJS/Prisma backend, SQLite для разработки, интеграцией 1С и модулем мониторинга цен 05.ru.

## Быстрый запуск

### Windows
Запусти `TEXHORU.exe`, если он уже лежит в локальной папке проекта. Исходный кроссплатформенный запуск: `TEXHORU-WINDOWS.cmd`.

### macOS
Двойной клик по `TEXHORU.command`. При первом запуске проект установит зависимости и Prisma. Для парсера на macOS может понадобиться отдельно установленный Chromium.

## Адреса

- Магазин: `http://127.0.0.1:5173/`
- Админка: `http://127.0.0.1:5173/admin`
- Backend: `http://127.0.0.1:3000`
- Health: `http://127.0.0.1:3000/api/health`

## Данные

Локальная база: `server/prisma/dev-local.db`.
Загруженные изображения: `server/uploads/`.
Локальные секреты: `server/.env.local`.

Эти файлы исключены из Git и не входят в clean-архив. При обновлении поверх существующей папки они сохраняются.

## Мониторинг цен 05.ru для сотрудников

Войти в админку: `http://127.0.0.1:5173/admin`, раздел **Мониторинг цен**.

1. **Первичная настройка (один раз):** после загрузки каталога из 1С нажать **«Найти непривязанные»**. Если конкретный товар не сопоставился, открыть его точную карточку на 05.ru, вставить URL в поле **«Привязать по ссылке»** и подтвердить. Привязки сохраняются в базе и не исчезают при перезапуске.
2. **Повседневная работа:** нажать **«Обновить цены 05.ru»**. TEXHORU открывает до 4 сохранённых ссылок параллельно в фоновом браузере, проверяет цены и наличие и сохраняет результаты в SQLite последовательно. Повторный поиск по названиям не выполняется.
3. **Если сайт ограничил доступ:** задача остановится с ошибкой 403/429, а оставшиеся ссылки сохранятся. После восстановления доступа нажать **«Продолжить обновление»**. Неудачная проверка не подменяет старую цену.
4. **Смена ссылки:** открыть **«Детали»**, нажать **«Снять привязку»**, затем указать новую карточку. Несовместимые характеристики не могут быть подтверждены.

**Проверка цен не изменяет цену продажи на сайте TEXHORU.** Отдельное изменение цен находится под **«Дополнительно» → «Применить цены к товарам TEXHORU»** и требует отдельного подтверждения рисков. 1С загружает исходные товары по уже настроенному обмену.

Скорость зависит от времени ответа 05.ru и ограничений сайта. Приложение не обходит блокировки 403/429 и не обещает обновить недоступные карточки.

## Основные модули

- каталог и карточки товаров;
- корзина и оформление заказа;
- личный кабинет и статусы заказов;
- админка каталога;
- управление акционными баннерами с кадрированием;
- интеграция 1С → TEXHORU;
- мониторинг цен 05.ru через Playwright;
- тестовый импорт товаров/разделов 05.ru;
- история цен и рекомендованная цена.
