# TEXHORU

Интернет-магазин электроники и панель управления ассортиментом, заказами и ценами с интеграцией 1С: Управление торговлей 10.3 и мониторингом 05.ru.

## Работа с магазином

| Раздел управления | Назначение |
| --- | --- |
| Главная | Состояние магазина и быстрые действия |
| Товары | Карточки, категории и видимость на витрине |
| Цены | Проверка 05.ru, точные привязки, подтверждение изменений |
| Номенклатура 1С | Поиск в зеркале каталога и выборочная загрузка на сайт |
| Заказы | Работа с заказами покупателей |
| Оформление | Управление витриной и рекламой |

Цена предлагается по правилу `max(05.ru − 100 ₽, закупочная)`. Неизвестная закупочная блокирует изменение. Парсер не отправляет цены самостоятельно: сотрудник подтверждает выбор, сайт публикует новую цену после подтверждения 1С.

## Запуск и обновление

**Рабочий сервер:** [Яндекс Cloud](docs/yandex-cloud.md) — установка, HTTPS, обновление, перенос данных и агента.

**Локальная разработка (Windows, macOS, Linux):** Node.js 22+.

Магазин: http://127.0.0.1:5173 · Админка: http://127.0.0.1:5173/admin

```bash
npm run dev
```

Для остановки из второго терминала: `npm run stop`.

Запуск автоматически подготавливает локальное приложение. Подробности: [локальный запуск](docs/one-click-start.md), [демонстрация через ngrok](docs/demo-ngrok.md). Журнал запуска: `.texhoru/startup.log`.

Не запускай `npm run reset:local` ради обновления: это отдельная операция сброса локальных данных с подтверждением.

## Структура проекта

| Папка | Содержимое |
| --- | --- |
| `src/` | React: витрина и админка |
| `server/src/` | NestJS: API, товары, заказы, цены, авторизация и интеграции |
| `server/prisma/` | Схемы базы данных |
| `onec/agent/` | Агент подтверждённого обмена ценами |
| `onec/catalog-agent/` | Агент чтения номенклатуры |
| `onec/monitoring/` | Исходники обработок 1С |
| `deploy/cloud/` | Развёртывание и обслуживание сервера |
| `scripts/` | Запуск, остановка и операции обслуживания |
| `public/` | Статические ресурсы |
| `tests/`, `server/tests/` | Автоматические проверки |
| `docs/` | Документация по темам |

## Проверка и безопасность

```bash
npm ci
npm --prefix server ci
npm run db:local:generate
npm run build:all
npm run test:project
npm --prefix server run test:monitor
```

Для локальной базы сначала настрой `server/.env.local` по примеру `server/.env.example` и проверь `DATABASE_URL`, затем выполни `npm run db:local:push`. Проверки CI: GitHub Actions.

Не коммить локальную базу, `server/.env.local`, загрузки `server/uploads/`, резервные копии и ключи. Не удаляй их при обновлении. Тестовую и рабочую базы 1С не смешивать; исходящий обмен разрешать только после отдельной проверки.
