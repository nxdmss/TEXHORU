# TEXHORU: чистый старт парсера

## Что сохраняется
Код, дизайн, плитки категорий, интеграция 1С и API. Сброс касается только локальных данных, а не GitHub или 1С.

## Что обнуляется
Локальная SQLite-база: товары, группы, подгруппы, история цен 05.ru, привязки, заказы, пользователи, промобаннеры, тестовые записи. Загруженные изображения тоже очищаются. Перед очисткой сохраняются резервные копии базы, настроек и фотографий в backups/.

## Чистая установка на Windows
1. Полностью закрой TEXHORU через TEXHORU STOP.exe.
2. Открой TEXHORU-RESET.cmd в корне проекта.
3. Введи точную фразу RESET-TEXHORU. Сброс откажется работать, если запущен локальный сервер.
4. Проверь созданную папку backups/automatic-clean-reset-*.
5. Запусти TEXHORU.exe: создастся пустая база с пользователем-администратором из server/.env.local.
6. Импортируй реальные группы, подгруппы и товары из 1С.
7. Сопоставь товары с 05.ru один раз и затем обновляй цены по прямым ссылкам.

Вместо кнопки можно использовать команду: npm run reset:local -- --confirm RESET-TEXHORU. Без подтверждения программа ничего не удаляет.

## Правила категорий
1С остаётся главным источником: GUID товара, GUID категории, полное название группы/подгруппы, цена и остаток. TEXHORU сохраняет эти данные при повторном импорте.
Категории отображаются в существующем дизайне плиток, по одному уровню, с кнопкой возврата и хлебными крошками. Никаких предустановленных фиктивных категорий.
Раздел «Популярное» показывает только реальные товары в наличии, по ассортиментной подборке. Это не статистика реальных продаж.

## Что дальше
Сперва проверяем парсер на 50, 200 и 2000 товарах. Сайт завершаем позже на той же модели данных через API TEXHORU. Для продакшна SQLite будет перенесена в PostgreSQL после тестов.

Осторожно: RESET предназначен для локальной тестовой копии. Не запускай его на рабочей базе магазина. Восстановление из backups выполняется отдельно.
