# Новый каталог TEXHORU — навигация по папкам и популярные iPhone

## Как работает

**Админка → Товары**: вместо раскрытого длинного списка 1С пользователь видит только текущий уровень дерева. Слева — название текущей папки, кнопка назад и её непосредственные дети. Справа — хлебные крошки и карточки подгрупп. Например: **МОБИЛЬНАЯ СВЯЗЬ → Смартфоны → Apple → iPhone 17 Pro / iPhone 17 Pro Max**. Внутри модели — реальные SKU. Переходы анимированы, поддерживаются клавиатура и мобильный экран.

**Витрина → Каталог**: та же логика по уровням; переход в раздел показывает заголовок, описание, подкатегории. На последнем уровне показываются товары. Поиск по всему каталогу остаётся независимым от категории. Категории, созданные из 1С, не переименовываются: названия линеек iPhone/Xiaomi/Galaxy — **виртуальные полки интерфейса**, не новые записи в базе, поэтому не затрагивают остатки, GUID, SEO-адрес товара и связи 05.ru.

**Главная**: до 10 реальных активных iPhone с положительным доступным остатком, выбираемых из API. На большом экране — 5 карточек в ряд, 2 ряда. В выборе соблюдается разнообразие: iPhone 17 Pro Max / Pro / базовая модель, затем другие поколения из наличия. Цена и остаток — только текущие данные TEXHORU, не копии из 05.ru.

## Фото товаров

Приоритет отдан собственным фотографиям, ранее загруженным в карточку. Если 1С прислала пустое фото или базовую заглушку, для линейки iPhone 17 используется один из **пяти специально нарисованных прозрачных SVG-вырезов** (оранжевый, синий, белый, зелёный, тёмный). Эти изображения локальные, быстро загружаются, без внешних сервисов и hotlink. Для старых поколений прежняя заглушка не заменяется чужим устройством.

Автоматическое копирование PNG с 05.ru не включено: прямой доступ к его медиа из среды разработки ограничен, а для коммерческого повторного использования чужих фото необходимо иметь разрешение правообладателя. Можно заменить SVG на разрешённые оригинальные PNG в `public/products/` и подключить их через обычное поле `image` товара в админке.

## Установка

Изменения затрагивают фронтенд и статические SVG, не добавляют миграции БД и не переименовывают папки 1С. Установить актуальный `main` через обычный способ обновления TEXHORU, сохранив БД, файлы и секреты. Перезапустить фронтенд и очистить кеш браузера. Проверить путь через **Товары → Мобильная связь → Смартфоны → Apple → iPhone 17 Pro** и главную с двумя рядами популярных моделей.
