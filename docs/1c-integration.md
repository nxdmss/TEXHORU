# Интеграция TEXHORU ↔ 1С

Локальная тестовая схема:

1. Пользователь записывает товар в 1С.
2. `ПриЗаписи` формирует JSON.
3. 1С отправляет POST на `http://127.0.0.1:3000/api/integrations/1c/catalog`.
4. NestJS сопоставляет категорию и товар, обновляет SQLite.
5. Витрина читает обновлённый каталог через API.

Для production категория не должна быть строкой. Используй отдельный справочник категорий и передавай его стабильный GUID в `oneCId` / `categoryOneCId`.
