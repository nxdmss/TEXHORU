# Интеграция TEXHORU ↔ 1С

Полная установка учебного обмена: [windows-1c-monitoring.md](windows-1c-monitoring.md).

Каталог 1С поступает через POST `/api/integrations/1c/catalog` с `x-1c-key` либо через загрузку JSON в админке. Каждый пакет применяется транзакционно. Дополнительно принимаются `gtin`, `mpn`, `attributes` и `costPrice`. Цена и остаток приходят из 1С.

Обратный мониторинг: GET `/api/integrations/1c/price-monitor/pending`, запись в отдельный регистр 1С, затем POST `/api/integrations/1c/price-monitor/receipts`. Сообщения повторяются до подтверждения, их ID стабилен. Ошибка записи оставляет результат в очереди. Отмена или изменение сопоставления исключает ожидающие результаты из обмена.

В `onec/monitoring` — тексты общего модуля и формы для файловой учебной базы со справочником Товары. Скомпилированной обработки/расширения и адаптера для коммерческих конфигураций в пакете нет. Старый модуль `ПриЗаписи` совместим с каталогом, но не экспортирует расширенные характеристики; новый обработчик выгружает полный каталог по кнопке.
