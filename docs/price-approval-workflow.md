# TEXHORU — ежедневная работа с ценами

## Для руководителя
1. В 06:00 (московское время) TEXHORU проверяет **уже подтверждённые** карточки 05.ru, если работает сервер и включена автопроверка.
2. Откройте **Админка → Мониторинг цен → Предложения**. Категории и подкатегории повторяют пути категорий, выгруженные из 1С.
3. Посмотрите нашу цену, цену конкурента и предложенную цену. Отметьте нужные товары.
4. **Применить выбранные**: цена на сайте обновится, а задание уйдёт в очередь 1С. Это ещё не подтверждение записи в 1С.
5. **Не менять выбранные**: сохраняет отказ от конкретного предложения. Если изменится цена конкурента или наша цена, предложение может появиться снова.
6. **Админка → 1С**: смотрите понятные статусы «Ожидает 1С», «Цена обновлена в 1С», «Нужна проверка».

## Защитные ограничения
- Автоматический парсер **не меняет** цены сам.
- Применяются только явно отмеченные предложения и только товары, подключённые к обмену ценами с 1С.
- Проверенная привязка по товарной модификации (модель, память, цвет), актуальная цена (не старше 24 часов), наличие у конкурента.
- Для предложений требуется известная закупочная цена, минимальная маржа (по умолчанию 5%, регулируется MONITOR_MIN_MARGIN_PERCENT на сервере) и изменение не более 10%.
- Если на товар уже есть ожидающая запись в 1С, второе задание не создаётся.
- Применение выбранной партии транзакционно: при ошибке данные не меняются частично.
- Каждая операция фиксируется в аудите. Отказ не удаляет историю цен.
- Товары, не прошедшие ограничения, пропускаются. Не угадывайте цену закупки.

## Настройка запуска в 06:00
В **Мониторинг цен → Настройки и инструменты специалиста** включите автопроверку.
Сервер использует расписание 06:00 по Москве (UTC+03, круглогодично) для новых настроек 05.ru. Для уже существующих настроек включите переключатель вручную. Старая периодическая настройка сохраняется, пока её не поменяют.
Планировщик живёт в сервере TEXHORU и сохраняет следующую проверку в БД. Сервер должен работать постоянно; после простоя просроченная проверка стартует при следующем запуске.
Товары без подтверждённой привязки автоматически не ищутся: их нужно один раз сопоставить в инструментах специалиста.

## Следующий этап — отдельный агент 1С
Сейчас тестовая обработка 1С запускается вручную. Автопроведение в 1С **не включено**.
Когда согласуем обслуживание, подключаем отдельный агент на Windows с доступом только к TEST, тестируем повторные запросы, резервную копию, отсутствие связи с PROD и подтверждение документа. После проверки и разрешения владельца возможно отдельное внедрение на рабочей базе.
Для постоянной связи нужен защищённый стабильный адрес TEXHORU вместо ngrok на пользовательском VPN.
