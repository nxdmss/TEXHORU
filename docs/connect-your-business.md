# Как подключить свой магазин к TEXHORU без парсинга поиска 05.ru

## 1. Товары и остатки из 1С

В запущенном TEXHORU открой **Админка → Цены конкурента → Мои товары → Подключить товары 1С и цены конкурента**.

- Если обмен с 1С уже настроен: используй его. При загрузке существующего каталога TEXHORU обновляет товары по постоянному `oneCId`, не стирая остальные данные.
- Если есть файл выгрузки: загрузи **catalog.json** в поле «1. Каталог из 1С». Формат: `{"categories":[{"oneCId":"...","name":"Смартфоны","slug":"smartphones"}],"products":[{"oneCId":"...","sku":"...","name":"...","slug":"...","brand":"Apple","categoryOneCId":"...","price":91000,"stockQty":2}]}`.
- Для прямого обмена: `POST /api/integrations/1c/catalog`, заголовок `x-1c-key` со значением `ONE_C_API_KEY` из `server/.env.local`. Администратор может загружать тот же JSON через сайт, не передавая ключ в браузер.
- **УТ 10.3 реального бизнеса:** обработка для учебной 1С не является автоматически совместимой с УТ 10.3. Нужно адаптировать выгрузку к её реальным справочникам и характеристикам. Запуск тестового импорта не означает подключённую рабочую 1С.

Перед запуском с рабочей базой экспортируй небольшой набор товаров (5–10 позиций), проверь реальные GUID, варианты, цены, остатки, и только после этого расширяй обмен. В экспорт не включай персональные данные и документы покупателей.

## 2. Цены конкурента через Excel / CSV

1. Нажми **«2. Скачать шаблон CSV для Excel»**. Шаблон автоматически подставит `oneCId` и название из текущих товаров 1С.
2. Открой CSV в Excel. Введи точный адрес товара 05.ru в `url`, цену в рублях в `price`, дату наблюдения в `observedAt` (например, `2026-10-28T15:00:00+03:00`). `inStock`: «да», «нет» или пусто.
3. Сохрани как **CSV UTF-8, разделитель ;** (поддерживаются также запятая и табуляция). Пустые строки шаблона пропускаются.
4. Нажми **«3. Заполненный прайс (.csv / .tsv)»** и загрузи файл.

Пример строки:

```csv
oneCId;url;name;price;observedAt;inStock
<GUID из 1С>;https://05.ru/cat/396f7486/p/smartfon-apple-iphone-17-pro-12-gb-256-gb-oranzheviy-e-sim-bez-rustore-24007/;Смартфон Apple iPhone 17 Pro 256 Гб eSIM оранжевый;94990;2026-10-28T15:00:00+03:00;да
```

Точная ссылка и соответствие варианта обязательны. Допускается до 500 строк за раз; данные должны быть не старше 30 дней. Файл с ошибками отклоняется целиком, а не частично. Повторный импорт той же цены за ту же дату не дублирует историю.

**Это не способ автоматически получить достоверную цену 05.ru:** файл должен содержать цены из законного и актуального источника (ручная проверка, договорной прайс-фид или лицензированный поставщик мониторинга). Программа **не объявляет их проверенными на 05.ru**, не отправляет в 1С и не предлагает автоматически применить к сайту. Для автоматического обновления потребуется подтверждённый источник с API или прайс-фидом и отдельная интеграция.

## 3. Безопасное обновление

При замене файлов проекта не удаляй `server/prisma/dev-local.db`, `server/.env.local`, `server/uploads` и папку резервных копий. Сначала останови прежнюю версию, затем запусти `TEXHORU.exe`. Проверь, что свои товары 1С и четыре ранее подтверждённые связи на месте.

Реальная рабочая интеграция 1С не может считаться завершённой, пока мы не проверили экспорт настоящей базы УТ 10.3 и подтверждение результата в самой 1С.
