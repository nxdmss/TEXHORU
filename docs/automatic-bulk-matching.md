# Автоматическое сопоставление большого каталога 1С с 05.ru

## Для 2000+ товаров без ручной загрузки

1. Настрой передачу каталога, артикулов, характеристик, цен и остатков из своей 1С по `POST /api/integrations/1c/catalog` с ключом `ONE_C_API_KEY` (либо импортируй `catalog.json` один раз для теста). Контракт для УТ 10.3 требует адаптации к её настоящим метаданным; учебная обработка 1С не равна рабочей интеграции УТ 10.3.
2. В **Цены конкурента → Найти совпадения автоматически** выбери «Все группы из 1С» и 2000/5000 товаров.
3. TEXHORU создаст отдельную длительную задачу `INDEX_05RU` до сопоставления: посетит публичную страницу продавца `https://05.ru/cat/seller/05-ru-133/`, затем `?page=2`, `?page=3` и так далее. Каждая страница записывает найденные название/URL/модель/память в отдельную индексную таблицу. Индекс не является подтверждённой ценой.
4. После окончания индексации программа продолжит сохранённую очередь `MATCH_1C`: по модели и памяти находит варианты, проверяет цвет/SIM, заново читает **страницу конкретного товара** 05.ru для актуальной цены и сохраняет связь. Неоднозначные совпадения отклоняет, не выбирает произвольные SKU. Цена собственного товара автоматически не меняется.
5. Прогресс сохраняется в SQLite. Если компьютер/программа перезапускается, незавершённые задачи продолжаются по сохранённому курсору. Если 05.ru ограничивает запросы или перестаёт отдавать новые страницы, индексатор останавливается с диагностикой и **не запускает 2000 поисков на неполном индексе**. Обход ограничений доступа не выполняется.
6. Следующий массовый запуск использует индекс, если он успешно построен за последние 7 дней; свежие цены всё равно проверяются на отдельных карточках.

## Пределы

- 2100 страниц — технический предохранитель, не утверждение о полноте сайта 05.ru. Если сайт не раскрывает все страницы или меняет выдачу, индексация не может гарантировать полную базу.
- Если отдельные карточки 05.ru не открываются, получить актуальные цены нельзя даже при совпавших наименованиях. Результат помечается как непроверенный. Не переключайся на ценники из старого каталога.
- При большом объёме выполнение занимает длительное время: не запускай несколько конкурирующих заданий. Задание выполняется в самой программе при включённом TEXHORU, не в ChatGPT.
- Для производственной надёжности предпочтителен разрешённый API/фид 05.ru или договорной поставщик прайса. Публично описанный API для продавцов предназначен для отправки их собственных каталогов на 05.ru; право читать полный прайс конкурентов по этому API не подтверждено.

## Проверка

Начни с 10–100 товаров только для проверки доступа к карточкам, затем запусти 2000. Перед запуском настоящего бизнеса убедись, что 1С передаёт верные GUID, модель/память/цвет и остатки. Тесты CI проверяют пагинацию и сохранение состояния, но не заменяют живой тест сайта 05.ru.
