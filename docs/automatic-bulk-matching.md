# Автоматический поиск и проверка цен 05.ru для товаров 1С

## Поиск по рабочей странице, без ручных ссылок

1. Товары и характеристики передаются из 1С существующим обменом `POST /api/integrations/1c/catalog`. Для настоящей УТ 10.3 необходим адаптер к её реальной структуре.
2. В **Цены конкурента → Найти совпадения автоматически** выбери группу и до 5000 товаров за задание. Предварительный обход всего каталога **по умолчанию не запускается**.
3. Для каждого товара TEXHORU открывает **прямой публичный поиск** `https://05.ru/search/?q=<модель и память>&page=1`. Это тот адрес, который пользователь проверил в реальном Chrome 28.10.2026. Главная страница 05.ru и её кнопка поиска не используются.
4. Полученные `a[href*="/p/"]` канонизируются и объединяются по URL. Поисковая выдача может содержать много повторов одного товара: в проверенном примере было 32 анкоры на 8 товаров. Неверная модель, аксессуары, неподходящий объём памяти (например, 1 ТБ вместо 256 ГБ) отбрасываются **до открытия карточки**.
5. Кандидаты открываются по своим прямым страницам 05.ru (не больше трёх одновременно). Цена и наличие извлекаются из основной карточки, а не из цены поиска или кеша. Существующие подтверждённые связи сохраняются.
6. Работа возобновляется по сохранённому курсору. При HTTP 403/429, таймауте, пустой выдаче или несогласованных характеристиках показывается причина; цена в 1С **автоматически не изменяется**.

## Старый режим индексации

Отдельный индекс `INDEX_05RU` сохранён для **явного включения API-параметром** `indexCatalog:true`, но он не проверен на полном ассортименте сайта и не используется по умолчанию. Защита от повторяющихся страниц и сохранение прогресса остаются.

## Ограничения

- В живом Chrome подтверждены поисковая выдача, ссылка на товар и отдельное успешное обновление цены 94 990 ₽. Это не доказывает работу Playwright в установленной версии TEXHORU до её запуска на том же компьютере.
- Частота и стабильность автоматических запросов к 05.ru зависят от доступности сайта. При ограничении доступа попытки обхода защит не выполняются.
- Начни с 5–10 товаров и проверь даты успешного обновления и отсутствие ложных совпадений; затем расширяй задание до всего ассортимента.
