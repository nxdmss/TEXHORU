# Быстрое обновление разрешённых товаров

TEXHORU и ngrok работают на компьютере демонстратора, агент — на компьютере с TEST 1С.

На экране **Цены** три группы:

- **Готовы к обновлению** — обмен разрешён, привязка подтверждена, есть свежая проверенная цена, отличающаяся от нашей.
- **Ждут 1С** — цена уже отправлена, повторная отправка исключена.
- **Нельзя обновить** — рядом с товаром короткая причина: нет разрешения, привязки, цены, остатка, нужна свежая проверка или цена уже актуальна.

Нажми группу, чтобы раскрыть список. В готовых товарах можно выбрать раздел, найти название, отметить отдельные позиции или выбрать все готовые. Фильтр списка сам не меняет выбранные товары: для раздела нажми **Выбрать найденные**.

**Обновить готовые (N)** передаёт только эти N позиций. Здесь нет поиска новых карточек и повторного сканирования 05.ru: используются уже проверенные данные не старше 24 часов. Для обновления самих данных есть **Проверить цены разрешённых**: она перечитывает только сохранённые подтверждённые карточки активных разрешённых товаров. Если разрешено 30 из 150, остальные 120 не проверяются этой кнопкой.

Список разрешений не меняется автоматически. Его можно дополнить в **Настройки и привязки → Товары для обмена с TEST 1С** в пределах 30 позиций. Поиск и исправление привязок остаются в отдельном свёрнутом блоке **Настройки и привязки**.

Цена — подтверждённая цена 05.ru минус 100 ₽. В TEST ограничение изменения 10% временно отключено. Модель, память, цвет, SIM, состояние, наличие, остаток, свежесть и неизменность привязки проверяются перед постановкой в очередь. Разрешения и цены перечитываются в транзакции; снятое разрешение блокирует передачу.

**Что обновилось** содержит результат последнего запуска. Только квитанция 1С даёт статус **Обновлено** и меняет цену сайта. Сервер хранит операцию и очередь между перезапусками; повторное нажатие во время операции не создаёт дубликат. **Остановить подготовку** сохраняет уже отправленные изменения.

Открытие экрана и автоматическое обновление счётчиков читают только базу данных. Они не запускают парсер. Проверка реального проведения документов, EPF и планировщика Windows выполняется на компьютере с TEST 1С.
