# Обновление цен

Все товары, загруженные из 1С на включённый TEST-сервер, подключаются автоматически. Общего лимита в 30 товаров нет. Агент передаёт цены небольшими партиями.

В **Цены** три группы:

- **Готовы** — подтверждённая связь и свежая цена, отличающаяся от нашей.
- **Ждут 1С** — изменение отправлено, ожидаем квитанцию.
- **Нужна проверка** — краткая причина рядом с товаром; актуальные цены тоже здесь.

**Проверить цены** перечитывает сохранённые карточки 05.ru. **Обновить все (N)** отправляет только готовые изменения. Для части товаров раскрой **Готовы**, выбери раздел или название, затем **Выбрать найденные**.

Для новых товаров: выгрузи группу из TEST, открой **Связи с 05.ru → Найти совпадения**. Поиск учитывает фильтры и пропускает существующие связи. Спорные варианты требуют подтверждения; ручная ссылка доступна в строке товара. Инструкция выгрузки свёрнута под списком.

Цена — 05.ru минус 100 ₽. Модель, память, цвет, SIM, состояние, наличие, остаток и свежесть проверяются перед отправкой. Кнопка обновления цен не ищет новые карточки. Снятая или изменённая привязка блокирует передачу.

Только квитанция 1С даёт статус **Обновлено** и меняет цену сайта. Результат свёрнут в **Что обновилось**. Очередь сохраняется между перезапусками; повторное нажатие во время операции не создаёт дубликат. **Остановить подготовку** сохраняет уже отправленные изменения.

Открытие экрана и обновление счётчиков не запускают парсер. Реальное проведение документов и планировщик Windows проверяются на компьютере TEST 1С.
