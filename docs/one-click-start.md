# Локальный запуск

Для локального запуска установи Node.js 22+ и выполни `npm run dev` в корне проекта. Для остановки — `npm run stop`. На Windows парсер 05.ru использует уже установленный Microsoft Edge через Playwright в headless-режиме с временным изолированным профилем. Отдельный Chromium при первом запуске не скачивается.

Подготовка вычисляет отпечаток исходников и зависимостей. Приложение копируется в новый каталог `%LOCALAPPDATA%/TEXHORU/cache/<project-id>/app-*`; туда устанавливаются зависимости. Старый node_modules пользователя не очищается и не используется. Это устраняет удаление заблокированной папки react-native/React, на котором упал прежний npm ci в OneDrive.

Prisma client и backend собираются в кеше. DATABASE_URL указывает на оригинальную SQLite-базу, TEXHORU_UPLOADS_DIR — на оригинальные фотографии. Перед новым изменением схемы копируются база с журналами, env и фотографии. Seed выполняется только для новой базы, с сохранением признака незавершённого первого создания. Существующая учётная запись не пересоздаётся.

Повторный запуск использует подготовленный кеш. При изменении кода собственная работающая копия останавливается через локальный управляющий канал с непредсказуемым токеном. Посторонние процессы не завершаются. Старую копию без этого канала потребуется закрыть вручную один раз.

Backend получает завершение по IPC, закрывает NestJS/Prisma и только затем заканчивает работу. Если Edge отсутствует, сам магазин запускается, а парсер сообщает об отсутствии браузера вместо зависания на большой загрузке. Команда `npm run stop` использует тот же защищённый управляющий канал. Неавторизованная команда остановки отклоняется.

Проверено: первый запуск из папки с пробелами и OneDrive в пути; старая папка зависимостей остаётся нетронутой; повторная подготовка использует кеш; сайт отвечает; фотографии читаются из оригинальной папки; существующие товары, цены, остатки, резервы и пароль администратора сохраняются; повторное открытие не создаёт второй экземпляр; остановка завершает процессы приложения. Эти исполняемые проверки проведены в Linux. Прежние EXE-пускатели исключены из корня репозитория; исходники сохранены.

Исходники прежнего Go-пускателя сохранены в `scripts/launcher/` для совместимости и истории; для обычного запуска он не требуется.
