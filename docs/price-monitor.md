# Мониторинг цен

Инструкция установки на Windows и обмена с учебной 1С: [windows-1c-monitoring.md](windows-1c-monitoring.md).

Парсер сохраняет отдельный каталог конкурента. Сопоставление предлагает кандидатов по характеристикам и идентификаторам; подтверждённые результаты передаются в 1С через очередь с подтверждениями. Собственная цена сайта модулем не меняется. Старый `apply-recommended` возвращает объясняющую ошибку.

Обход раздела — фоновая задача с сохраняемым курсором и ограничением страниц. Расписание проверяет сохранённые карточки и по умолчанию выключено. HTTP 403/429 останавливает задачу; обход защиты не выполняется.

Ранее созданные тестовые товары остаются в базе. Совместимый тестовый импорт создаёт DRAFT-товары без реального остатка; основной интерфейс использует отдельный каталог мониторинга.


## Автопоиск 1С → 05.ru

Поиск сначала нормализует модель и память, убирая внутренние пометки 1С (например, EAC). Для популярных смартфонов формирует два запроса: модель с объёмом памяти, затем только модель. Ссылки из результатов ранжируются по модели и памяти **до** выбора 12 карточек для проверки. После загрузки карточек повторно проверяются модель, память, цвет и конфликты атрибутов. Неоднозначные варианты требуют подтверждения; никаких автоматических изменений цен.

Админка → Мониторинг цен → Мои товары → «Найти совпадения». После задачи открой «Почему не найдено совпадение?». В диагностике будут поисковые запросы, количество ссылок, количество прочитанных карточек и примеры причин отклонения. Если ссылок много, но карточки не читаются, это **ошибка парсинга**, а не доказательство отсутствия товара. При запрете доступа 403/429 задача приостанавливается без обхода защиты.

Для быстрой проверки конкретного товара вставь его реальную ссылку 05.ru через «Добавить ссылку» → «Один товар». Тест через локальную Windows-сборку и настоящую 1С УТ 10.3 обязателен перед запуском на рабочем магазине.
