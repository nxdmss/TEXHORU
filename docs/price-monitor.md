# Мониторинг цен TEXHORU

Модуль находится в админке: **Мониторинг цен**.

## Проверка одной карточки 05.ru

1. Вставь ссылку на товар 05.ru.
2. При необходимости сопоставь её с товаром TEXHORU.
3. Backend открывает страницу через Chromium/Playwright.
4. Сохраняются название, текущая цена, старая цена, наличие и история проверок.
5. Для сопоставленного товара считается рекомендация: `цена 05.ru − 500 ₽`.
6. Кнопка применения меняет локальную цену TEXHORU. Следующая синхронизация из 1С может её перезаписать.

## Тестовый импорт раздела 05.ru

Импорт создаёт отдельные категории `ТЕСТ 05.ru · ...` и товары с SKU `05RU-*`.

Для теста копируются фактические поля: название, бренд, цена, наличие и раздел. Чужие фотографии и описания не копируются. Тестовый импорт можно удалить отдельной кнопкой, не затрагивая обычный каталог.

## Chromium

Скрипт запуска проверяет наличие Chromium Playwright и при необходимости устанавливает его автоматически.
