# Мониторинг цен

Инструкция установки на Windows и обмена с учебной 1С: [windows-1c-monitoring.md](windows-1c-monitoring.md).

Парсер сохраняет отдельный каталог конкурента. Сопоставление предлагает кандидатов по характеристикам и идентификаторам; подтверждённые результаты передаются в 1С через очередь с подтверждениями. Собственная цена сайта модулем не меняется. Старый `apply-recommended` возвращает объясняющую ошибку.

Обход раздела — фоновая задача с сохраняемым курсором и ограничением страниц. Расписание проверяет сохранённые карточки и по умолчанию выключено. HTTP 403/429 останавливает задачу; обход защиты не выполняется.

Ранее созданные тестовые товары остаются в базе. Совместимый тестовый импорт создаёт DRAFT-товары без реального остатка; основной интерфейс использует отдельный каталог мониторинга.


## Автопоиск 1С → 05.ru

TEXHORU использует двухступенчатую схему, как типовые системы мониторинга ассортимента: **сначала обнаружение каталога, затем чтение карточек и проверка цены**.

### Массовые запуски

Для выборки от 30 товаров интерфейс автоматически запускает построение локального индекса публичного каталога продавца 05.ru:

1. Читает страницы каталога с сохранением URL и названия товара.
2. Нормализует модель, память и цвет в локальном индексе.
3. Сопоставляет каталог 1С с индексом без отдельного поискового запроса на каждый SKU.
4. Открывает подходящие карточки 05.ru и проверяет реальные характеристики и текущую цену.
5. Если для конкретного товара индекс не дал кандидата, использует живой поиск 05.ru.

Индекс не является источником цены. Цена и наличие сохраняются только после успешного чтения самой карточки товара. Каталог повторно индексируется не чаще одного раза в семь дней при успешном завершении предыдущего прохода. Максимум прохода — 2300 страниц; повтор страницы или защитный лимит помечают индекс как неполный, и массовое сопоставление не продолжается на неполных данных.

Для небольших диагностических запусков используется живой поиск без предварительной полной индексации.

### Живой поиск и варианты

Поиск нормализует названия 1С, удаляет внутренние пометки (например, EAC) и формирует несколько запросов. Для смартфонов прямые результаты объединяются с публичным каталогом смартфонов 05.ru; каталог используется даже тогда, когда поиск уже вернул ссылки, но они могут быть нерелевантными.

Ссылки ранжируются по типу товара, модели, бренду, памяти и цвету до чтения карточек. После открытия карточки характеристики проверяются повторно. Для аксессуаров совместимость по модели телефона может создать предложение SUGGESTED; автоматическое подтверждение требует точного GTIN/MPN. Несколько близких вариантов сохраняются для ручной проверки, а не выбираются наугад.

### Диагностика

Админка → Мониторинг цен → Мои товары → «Проверить раздел». Во время массового первого запуска интерфейс показывает прогресс индексации по страницам. После задачи открой «Диагностика поиска»: там будут запросы, количество найденных ссылок, прочитанных карточек и причины отклонения.

Если ссылок много, но карточки не читаются, это ошибка чтения, а не доказательство отсутствия товара. HTTP 403/429 останавливает задачу. Ограничения доступа не обходятся.

Для быстрой проверки одного товара вставь реальную ссылку 05.ru через «Дополнительно» → «Проверить одну ссылку». Перед рабочим использованием проверь процесс на тестовой выборке и убедись, что обмен с 1С не применяет цены без твоего отдельного подтверждения.


### Если встроенный поиск 05.ru не отдаёт ссылки

TEXHORU сначала пробует штатный поиск 05.ru. Когда тот возвращает 0 карточек, программа читает **публичный каталог смартфонов** по адресу `https://05.ru/cat/mc/396f7486/smartfony/`. Обход ограничен четырьмя страницами и максимум 140 ссылками; индекс кешируется на 15 минут. Ссылки ранжируются по модели и памяти, а **цена берётся только из успешно открытой карточки товара 05.ru**, не из индекса или сохранённой старой цены.

Если сам каталог заблокирован или не загрузился, задача показывает ошибку: нельзя считать, что отсутствует товар или что цена была обновлена. Отсутствие подходящей модели среди прочитанных четырёх страниц также не доказывает отсутствия товара на всём сайте.

Для диагностики на рабочем компьютере открой через обычный браузер указанный каталог и конкретную ссылку товара. Если страницы не открываются и там, доступ TEXHORU к 05.ru необходимо проверить отдельно. Ограничения доступа не обходятся.
