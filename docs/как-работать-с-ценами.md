# Как работать с ценами

Эта инструкция для сотрудника магазина. Ниже только то, что действительно нужно нажимать.

## Проверка цен

1. Открой **Управление магазином → Цены**.
2. Нажми **«Проверить цены»**. Если ежедневная проверка включена, цены собираются автоматически.
3. Посмотри список предложений. Для каждого товара видны цена 05.ru, наша цена и предлагаемая цена.
4. По умолчанию предложение считается так: **цена 05.ru − 100 ₽**.

Первая проверка уже может показать разницу. Ждать, пока цена на 05.ru изменится второй раз, не нужно.

## Как отправить новые цены

1. Просмотри предложения и проверь нужные товары по ссылке **«Открыть 05.ru»**.
2. Поставь галочки рядом с подходящими товарами или выбери все доступные.
3. Нажми **«Отправить выбранные в 1С»**.
4. Подтверди отправку.
5. В разделе **«Обмен с 1С»** проверь, получено ли подтверждение.

**Парсер не отправляет цены сам.** Пока 1С не подтвердила проведение документа, старая цена остаётся на сайте.

## Почему товар нельзя выбрать

Под названием есть причина. Чаще всего это:

- **Нет связи с 05.ru.** Открой «Связи с 05.ru», найди товар и сопоставь его с правильной карточкой.
- **Данные устарели.** Нажми «Проверить цены» и дождись окончания.
- **Нет допуска к обмену с 1С.** Открой раздел «Обмен с 1С»; разрешение выдаётся только для тестовой базы и должно быть настроено заранее.
- **Изменение больше 10%.** В TEST временно разрешено; остальные проверки сохраняются.
- **Уже отправлено.** Дождись результата предыдущей отправки.
- **Нет остатка.** Сначала обнови сведения о наличии из 1С.

Товары без себестоимости **временно не блокируются**. Это не гарантия прибыли: перед подтверждением нужно самому знать закупочную цену.

## Если программа привязала не тот товар

Сравни точную модель, память, цвет и другие характеристики. Например, **чёрный** и **зелёный** телефон нельзя автоматически считать одинаковыми.

Открой **«Связи с 05.ru» → нужный товар → «Детали» → «Снять привязку»**, затем выбери правильную карточку. Пока привязка неправильная, цены не отправляй.

## Что можно делать автоматически

- Проверять цены каждый день.
- Сохранять историю найденных цен.
- Показывать расхождения и причины блокировки.
- После твоего подтверждения передавать выбранные изменения агенту тестовой 1С.

**Не включено:** самостоятельное решение о розничной цене, массовая отправка без выбора, запись в рабочую 1С без отдельного допуска.

Если передача зависла, не нажимай кнопку много раз. Сначала посмотри состояние в разделе «Обмен с 1С».
